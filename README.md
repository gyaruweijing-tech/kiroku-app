# Kiroku（記録）

酔ってても進捗だけは残せる、超シンプルな進捗・プロジェクト管理アプリ。
Markdown でプロジェクトのメモ／進捗を書き溜める。

## 起動
```bash
npm install
npm run dev
```
→ http://localhost:3000

## 使い方
- 左の一覧から開く／「＋ 新規プロジェクト」で追加
- **編集**タブで Markdown を書く（自動保存）
- **プレビュー**タブで整形表示
- ステータス（進行中／保留／完了）を切替
- **書き出し**で `.md` 保存、**読み込み**で `.md` 取り込み

## 構成
- `app/page.tsx` … 画面（UI）
- `lib/types.ts` … データの型（契約）
- `lib/storage.ts` … 保存ロジック（**ここを差し替えれば保存先を変えられる**）
- `lib/seed.ts` … 初期データ

詳しい進捗・改良メモは [PROGRESS.md](./PROGRESS.md) を参照。
